# 引継ぎ

作業を別の担当、セッション、環境へ渡す前に、次を満たす。

- 現在の目的と完了条件が `TASKS.md` にある
- 作業済み、未作業、保留が区別されている
- 変更ファイルと未コミット差分が説明されている
- 実行したテストと結果が記録されている
- 重要な決定が `DECISIONS.md` にある
- 現在の担当（routing）が記載されている
- 有効な承認条件が記載されている
- 正本に未記録の判断が記載されている
- 調査済み事項が記載されている
- `STATUS.md`を更新し、コミット済みである
- 秘密情報を含まない

引継ぎ文は `templates/development/HANDOFF_TEMPLATE.md` を使う。受け手は説明を鵜呑みにせず、リポジトリの状態と照合してから再開する。
