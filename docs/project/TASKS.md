## 状態の定義

- `未着手`: 作業開始前
- `進行中`: 担当が作業中
- `レビュー待ち`: 実装報告済み
- `修正中`: レビュー指摘へ対応中
- `判断待ち`: 人間の決裁が必要
- `ブロック`: 外部条件待ち
- `完了`: REVIEWERがPASSしPMが受入済み
