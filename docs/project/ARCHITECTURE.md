## データと状態

- localStorageキーはexpense-prototype-v2。v2がない初回だけ旧expense-prototype-v1から移行し、v1は書換え・削除しない。v2がある場合に旧版へ自動で戻さない。
- 旧申請は旧ルートと履歴を保持。申請には提出時のルート版と工程を写し、設定変更・停止を遡及させない。履歴は移行後の添付本体も保持するがブラウザー容量に制約がある。
- 承認額・実績フラグ・ルート識別等の欠損や工程矛盾は読込み・保存・遷移で拒否し、推測補完せず原文を保全して止める。正常な承認額以下の実績・購入済み再申請・旧互換は回帰検証済み。
